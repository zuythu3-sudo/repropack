# Examples

`failure.repropack.json` is a synthetic report generated by ReproPack from a
small command that exits with a non-zero status. Its credential and path values
are intentionally fake. The checked-in report exists so readers can inspect the
format without running a command.

`failure.github.md` is the result of rendering that validated report with:

```sh
repropack render examples/failure.repropack.json --format github
```

Never use real credentials, private paths, or proprietary logs in examples or
public bug reports.
